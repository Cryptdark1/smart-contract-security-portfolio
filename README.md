🎯 About This Repository

This is my personal smart contract security research portfolio. It documents selected vulnerability investigations, contest submissions, technical analysis, and lessons learned along the way.

The goal is not simply to collect findings, but to build a deeper understanding of how vulnerabilities arise, how to reason about their impact, and how protocols can be made safer.

You'll find:

- Security Findings: Write-ups of selected smart contract vulnerability investigations.
- Technical Analysis: Examinations of root causes, execution paths, and potentially broken security assumptions.
- Mitigation Ideas: Possible approaches to addressing the issues investigated.
- Lessons Learned: Notes from research, contest participation, and continued practice.

Contest outcomes are included transparently, including duplicate submissions. Each investigation is an opportunity to improve my ability to distinguish suspicious code from a demonstrable security vulnerability.
